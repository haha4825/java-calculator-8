## 1. 구현할 기능

- 문자열 입력받기  
- 커스텀 구분자 추출하기  
  - 커스텀 구분자는 한 개의 문자여야 한다.  
  - 여러 개의 커스텀 구분자를 정의할 수 있다. 
  - ex)
    ``` 
    //;\n//*\n1;2*3 => o
    //;*\n1;*2 => x
    ```
- 기본 구분자와 커스텀 구분자를 이용해 숫자 추출하기
- 잘못된 입력 시 `IllegalArgumentException` 발생 
  - 구분자로 .이 입력된 경우 double을 처리하기 위해 .은 커스텀 구분자로 사용할 수 없도록 한다.
  - 구분자와 숫자 외의 문자가 포함된 경우  
  - 양수가 아닌 입력
- 추출한 숫자들의 합 계산하기  
- 결과 출력하기

## 2. 제출 후 수정사항
- 제출 후 다른 분의 코드를 읽어보니 소수까지 처리하시는 것을 보고 기능 명세를 다시 읽어보니 양의 정수가 아닌 양수라고 적혀 있었다. 그렇다면 소수까지 처리하는 것이 맞다고 생각되어 수정하게 되었다.
- .을 특수 구분자로 지정할 수 없게하고 소수점 계산기로 바꾸어보자.
